# Roblox NPC Panel

Responsive demo dashboard for phones, tablets, and desktop browsers.

## Files
- `index.html` — responsive interface and local NPC counter simulation
- `manifest.webmanifest` — installable web-app metadata
- `sw.js` — basic offline cache after the first visit over HTTPS

## Enable GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for the Pages deployment to finish.

The project site should then be available at:
https://tulixpro.github.io/Bot/

## Privacy and scope
GitHub Pages websites are public on the internet by default, even if the source repository is private. Do not store passwords or personal information in these files. A password placed in browser-side HTML/JavaScript is not real access control.

This is only a local browser simulation. It does not connect to Roblox, create Roblox accounts, send reports, or send friend requests.
